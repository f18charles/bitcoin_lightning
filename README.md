# Bitcoin Lightning

A repository exploring Bitcoin Lightning Network concepts and implementations.

## Overview

This project contains learning materials and exercises related to Bitcoin's Lightning Network protocol, including multi-day structured lessons and setup configurations.

## Structure

- **day_1/** - First day's Lightning Network concepts and exercises
- **day_2/** - Second day's advanced Lightning Network topics
- **setup/** - Environment setup and configuration files

## Getting Started

Refer to the individual day directories for specific learning objectives and exercises.
